Configure, maintain, and/or troubleshoot enterprise-grade routers, firewalls, switches (e.g., Cisco, Palo Alto, Fortinet), WAN circuits (e.g., MPLS, Ethernet, point-to-point), ISP connections, configuring secure IPsec/SSL site-to-site, manage core network protocols (e.g., BGP, OSPF, EIGRP, STP, VLAN), and/or remote-access VPNs.
Conduct network vulnerability remediation, executing vendor patch management protocols, and perform firmware/OS updates across network devices to ensure adherence to cyber defense standards (e.g., FISMA, NERC-CIP, NIST 800-53, or PCI-DSS).

Operate and support Enterprise Network Access Control (NAC), DNS/DHCP/IPAM, NTP, Out of Band Management (OOBM), and/or authentication AAA systems (e.g., Cisco ISE, RADIUS, TACACS+, LDAP).
Use an enterprise monitoring platform (e.g., SolarWinds, PRTG, Cisco Prime, Splunk) to track performance metrics, network health, and/or maintain full asset inventories.
