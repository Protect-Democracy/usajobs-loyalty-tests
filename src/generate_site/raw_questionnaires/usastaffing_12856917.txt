Task: Validates claims for billing purposes ensuring eligibility and referring questionable coding for review.
When validating a high-dollar claim, a Medical Reimbursement Technician identifies a procedure code that is commonly rejected by the primary payer. The most appropriate self-managed action is to:
 Send the claim as-is, but make a mental note to check the payer website later that week for updates.
 Wait for the claim to be denied, as the denial process will automatically prompt a review.
 Change the code to a similar but less descriptive code that is known to pay without question.
 Immediately flag the claim, investigate the payer's most recent coverage policy for that procedure, and refer the specific questionable code or documentation to a certified coder or supervisor before submission.


2.
Task: Follows instructions about timeliness, objectives and relative priorities for doing work.
The MRT receives an urgent memo stating that all claims for Payer X must be submitted within the next 48 hours to meet a critical timely filing deadline. The MRT should prioritize this instruction by:
 Sending an email to the supervisor asking for clarification on which specific claims are most important, thereby delaying the start of the task.

 Ignoring the memo because it disrupts the existing workflow and only focusing on the oldest claims first, regardless of the deadline.
 Completing the original planned work for the day, and then working overtime to get the Payer X claims done, even if it risks the deadline.

Task: Submits claims to health Insurance Carriers.
